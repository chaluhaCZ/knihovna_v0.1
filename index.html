A small browser-based prototype

How to play

Find the Hiro marker to meet the fox. Collect it, then scan the Kanji marker placed on a book page to return it to its story.

This demo saves progress only in this browser on this phone. Camera access works on a published HTTPS website. Please allow camera access when prompted.

For the person setting up the demo

Print the marker sheet. Put the Hiro marker at the fox’s hiding place and the Kanji marker inside a book. Scan the first marker to collect the fox; scan the book marker and tap the return button.

This is a technical prototype, not yet a finished library game. Replace the sample markers with illustrated targets and add your own characters, stories, and accessible instructions.

Prototype: AR.js + A-Frame · No account or server database
