Library AR Hunt — printable targets

Print at 100% scale. Keep each marker square, flat, well lit, and visible. This sample uses the standard AR.js Hiro and Kanji markers; replace them with custom designs for a public-facing game.

Fox hiding place

Place this marker where the visitor finds the fox.

Return the fox to the book

Place this marker inside the book or on its marked page.

Marker images are standard AR.js examples. The browser app needs to be served from an HTTPS website to use the phone camera.
